Model Card — Churn Prediction
—
Algorithm
Gradient Boosting Classifier
Task
Binary Classification (churn / retain)
Target
Buyer before as_of = 2019-11-01 with no purchase in the next 30 days
Features
13 point-in-time features (recency, frequency, monetary, sessions, tenure, …) from events before as_of only
Evaluation
Stratified 80/20 user holdout; ROC-AUC and PR-AUC vs recency baseline
Tracking
MLflow — experiment: predix_churn_v1
Limitations
Single cutoff on two months of data; ~4M-event user sample; modest lift over baselines
Model Card — Upsell Scoring
Score
Algorithm
Rule-based gap scoring + RFM segmentation
Task
Regression / Ranking (opportunity score per category)
Formula
score = views − purchases × 8 (clipped ≥ 0)
Input
Category-level view/purchase counts + affinity matrix
Output
Ranked list of categories with highest unconverted demand
Tracking
MLflow — experiment: predix_upsell_v1
Use case
CRM campaigns, personalised push notifications, retargeting

dbt Layer Architecture
🟫 Bronze (raw)
· raw_events — direct source mapping
· No transformations; schema enforcement only
⬜ Silver (cleaned)
· events_cleaned — type casts, null handling
· sessions — session aggregation
· user_daily_agg — daily user metrics
🏆 Gold (features)
· customer_rfm — RFM scores & segments
· churn_features — ML-ready feature table
· upsell_features — opportunity scores
